# Security policy

Please read the project’s full [security and threat-model documentation](docs/SECURITY.md).

Do not open a public issue containing vulnerability details, credentials, founder data, contact data, or outreach content. Use GitHub’s private vulnerability reporting for this repository. Maintainers will acknowledge a report as soon as practical, assess affected versions, and coordinate remediation and disclosure with the reporter.

Only the latest commit on `main` is currently supported while FirstContact is pre-1.0.
